Інформаційна система для отримання, обробки та збереження даних з Riot API

Information System for Retrieving, Processing, and Storing Data from Riot API

Веборієнтована інформаційна система для автоматизованого отримання даних про гравців і матчі з Riot API, їх обробки, збереження в базі даних та подальшого використання для аналізу й візуалізації.

  • Ключові слова: Riot API, інформаційна система, Spring Boot, PostgreSQL, аналіз матчів
  • Автор: Співак Єгор
Репозиторій GitHub

Актуальність теми

Сучасні онлайн-ігри генерують великі обсяги даних про матчі, гравців та їхню активність. Використання таких даних є важливим для аналітики, побудови статистичних моделей і створення допоміжних сервісів для користувачів. Тому розробка системи, яка автоматизує отримання, обробку та збереження даних з Riot API, є актуальною практичною задачею.

Мета дослідження

Розробити інформаційну систему, яка забезпечує автоматизоване отримання, обробку та збереження даних про матчі й гравців із Riot API для подальшого аналізу та представлення через вебінтерфейс.

Основні завдання

  1. Проаналізувати можливості Riot API та визначити потрібні дані для системи.
  2. Реалізувати серверну частину для отримання та обробки інформації про матчі та гравців.
  3. Організувати збереження отриманих даних у базі даних PostgreSQL.
  4. Підготувати вебінтерфейс для представлення результатів роботи системи.
  5. Забезпечити перевірку працездатності за допомогою тестів і засобів безперервної інтеграції.

Методологія дослідження

У роботі використано підхід, що поєднує аналіз API, проєктування інформаційної системи, реалізацію серверної логіки та організацію збереження даних у реляційній базі даних.

  • Riot API використовується як джерело ігрових даних.
  • Spring Boot застосовується для реалізації backend-частини системи.
  • PostgreSQL використовується для збереження структурованих даних.
  • Maven застосовується для керування залежностями та збіркою проєкту.
  • Git та GitHub використовуються для контролю версій і документування процесу розробки.

Очікувані результати

  • Створення працездатної інформаційної системи для роботи з даними Riot API.
  • Автоматизація отримання та збереження даних про матчі та гравців.
  • Підготовка бази для подальшої аналітики, візуалізації та розширення функціоналу системи.
  • Формування прикладу практичного застосування сучасних інструментів веброзробки та backend-розробки.
