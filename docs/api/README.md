# API документація

Для інтерактивної документації API у проєкті використовується Swagger UI / OpenAPI.

## Запуск
Після запуску застосунку документація буде доступна за адресою:

```text
http://localhost:8080/swagger-ui/index.html
```

## OpenAPI JSON
Специфікація у форматі OpenAPI буде доступна за адресою:

```text
http://localhost:8080/v3/api-docs
```

## Що документується
- ендпоінти контролерів;
- параметри запитів;
- формати відповідей;
- короткий опис призначення API.
